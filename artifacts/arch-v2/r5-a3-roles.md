**o3c 열림만: P 74.3% / R 53.1% / R_bank 43.1% / 표 토큰 14.1%**

**o3c-llm 열림만: P 83.3% / R 71.4% / R_bank 56.9% / 표 토큰 14.7%**

- 기준선(R5-A2 d-llm 5회): P 65.0~70.7%, R 53.1~59.2%, R_bank(같은 분모 58쌍) 41.4~46.6%.
  노이즈 바닥은 R5-A2 값(P 11.5pp, R 11.3pp)이다.
- 규칙 판본(o3c)은 R을 올리지 못했다(base1 대비 -6.1pp, 열림만).
  같은 규칙에 언급 역할만 LLM으로 바꾼 o3c-llm은 R +12.2pp(base1 대비, base1~5 대비 +12.2~+18.4pp)로 노이즈 바닥을 넘었다.
- 규칙 대 LLM 차이: R 18.4pp(노이즈 바닥 11.3pp 초과), P 9.0pp(노이즈 바닥 11.5pp 안).
  규칙이 LLM 상한보다 노이즈 넘게 낮다.
- 언급 역할 일치율(규칙 대 LLM)은 59.9%(836/1,396)다.
  표본 판독(언급 40)은 판독 대 LLM 90.0%, 판독 대 규칙 47.5%다(3절).
- 표 토큰은 열림만 표도 최대 14.1~14.7%라 분기 문턱(기준선 recall의 10% 이내)을 넘는다.

- 측정 설정 4개(o3c 열림만, o3c-llm 열림만, o3c 전체, o3c 열림만 + o1c).

### 언급 찾기와 역할 규칙

- 본문을 문장으로 나누고(줄바꿈, `.`·`!`·`?`·`。` 뒤 공백, 펜스 코드 블록은 지움) 문장마다 `extract_keys(문장, item: 태그를 뺀 태그, 별칭 표)`를 불렀다.
- 기억마다 (문장 키 합집합 ∪ item 태그 키)를 기억 메타 `keys`와 비교했다.
  **다른 기억 0**(430 중), 문장에만 있는 키 0, 메타에만 있는 키 0이다.
  item 태그에서만 나온 키(역할 = 참조)도 0이다.
- 규칙 역할 순서: 문장의 열림 표지어 -> 끝냄 표지어 -> (첫 문장이면) 라벨 `[...]`.
  한 문장에 열림·끝냄이 같이 있으면 열림이고, 한 기억 안에서는 열림이 이긴다.
  표지어 목록은 모듈 머리 주석에 있다.
- LLM 역할(o3c-llm): `claude-haiku-5-5`에 언급 문장과 키만 40개씩 묶어 줬다(`bench/d_llm.py` claude 호출 경로).
  게이트웨이에는 넣지 않는다.
  응답 모델은 `modelUsage` 키로 `claude-haiku-5-5`임을 확인했다.
- 상태(o3c): t 이전 마지막 비참조 언급의 역할이다.
  같은 시각의 기억이 갈리면 열림이고, 참조만이면 미정이다.
- o3a: 키가 하나인 완료 계열 기억만 끝남 근거로 쓴다.
  o3b: 완료 계열 기억 중 그 키 언급 문장에 '남은 일·다음·후속·진행·대기·미완'이 있으면 끝남 근거에서 뺀다.
  둘 다 R5-A2 o3 규칙(완료 근거가 있으면 끝남)의 변형이다.
  변형 없는 판본이 R5-A2 `status_table`과 같은 결과를 내는지 테스트로 고정했다.

### 표

- 범위는 R5-A2 o3와 같은 질의 범위 프로젝트(프로젝트 상태 질의 + 요청 가족의 project)다.
- 전체 표: 범위 안 키 전체 상태(열림/끝남/미정). 열림만 표: 열림 키 + 최근 끝남 N=7일(끝남 날짜가 t-6 ~ t, KST).
  열림만 표 머리에는 "여기 없는 키는 뱅크 기억 기준 열림이 아니거나 질의 범위 밖"이라는 한 줄을 뒀다.
- 줄 형식은 R5-A2 o3와 같다(`키 | 상태 | 날짜 | 근거 id`).
- 표 토큰 = 표 텍스트의 tiktoken `cl100k_base` / 그 t의 필터 뒤 d-llm 입력(200,000자 상한 뒤, 행 렌더 텍스트) 토큰.
  분모는 t별 60,525~76,724 토큰이다.
- o1c: o3c 상태가 끝남인 키를 말하는 recall 행마다 o1 형식 주석 `[항목 상태: <키> 끝남 <날짜> 근거 <id>]`을 붙였다.
  근거는 그 키의 최신 끝냄 언급이다.
  완료 계열 행도 포함해 모든 행에 붙였고, 라벨셋으로 키를 고르지 않았다.

## 3. 규칙 대 LLM 일치율과 표본 판독

언급 1,396개 전체(규칙 -> LLM):

| 규칙 \ LLM | 끝냄 | 열림 | 참조 |

| 열림 | 95 | 219 | 44 |
| 참조 | 58 | 153 | 232 |

- 일치 **59.9%**(836/1,396).
  가장 큰 불일치는 규칙 참조 -> LLM 열림 153(표지어 없는 열림 언급)과 규칙 끝냄 -> LLM 열림 117이다.

| 비교 | 일치 |
|---|---|
| 판독 대 LLM | **90.0%**(36/40) |
| 판독 대 규칙 | **47.5%**(19/40) |
