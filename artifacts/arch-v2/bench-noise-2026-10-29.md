## 권장 허용 폭 (1단계 완료 기준 3)

"기준선 arm보다 나빠지지 않는다"의 "나빠짐" 문턱이다. 아래는 이 조건(`--split dev --limit 40 --seed 13 --rounds 3`, 같은 run 안에서 후보/기준 비)에서의 A/A 흔들림이다. 후보가 true 차이가 없는 같은 코드여도 이만큼은 흔들리므로, 문턱이 이보다 좁으면 거짓 악화가 난다.

산식: 점추정 허용 폭 = `|평균 비 - 1| + k x 표준편차`, `k = t(0.95, 자유도 4) x sqrt(1 + 1/5) = 2.1318 x 1.0954 = 2.335`(n=5에서 다음 1회 run의 95% 단측 예측한계). CI 상한 규칙 허용 폭 = `max(run별 CI 상한) - 1`. 결과는 **0.5% 단위로 올림**한다(0.98% -> 1.0%, 3.71% -> 4.0%, 8.14% -> 8.5%, 1.44% -> 1.5%). 이전 초안의 `2 x 표준편차`("약 95%")는 n=5에서 실제 커버리지가 약 93%라 이 산식으로 바꿨다.

| 축 | 권장 허용 폭 | 산식·근거 |
|---|---|---|
| 정확도 | **0** (identical 아니면 악화) | 5 run x 40쿼리 전부 identical, 기준 팔 비결정 0. 흔들림 0이므로 폭을 줄 근거가 없다 |
| 비용(토큰) | **0** (쿼리별 기준 최대 초과 시 악화) | 토큰이 결정적이다(5 run 합계 동일, 쿼리별 변화 0) |
| 속도 평균(기하평균 비) | **1.0%** (점추정). CI 상한 규칙을 쓰면 **1.5%** | 점추정: 0.0022 + 2.335 x 0.0032 = 0.0098 -> 1.0%. CI 상한 규칙: 최대 1.0144 -> 1.5%. 현 판정기의 고정 m=1%는 CI 상한 규칙에서 A/A 5회 중 2회(r4, r5)를 비열등으로 못 본다(상한 1.0144, 1.0125 > 1.01) |
| 꼬리 p95 | **4.0%** (점추정) | 0.0051 + 2.335 x 0.0137 = 0.0371 -> 4.0%. CI 상한 규칙은 최대 1.0697(7.0%)이라 이 조건에서 쓸 수 없다 |
| 꼬리 p99 | **8.5%** (점추정, 참고용) | 0.0096 + 2.335 x 0.0307 = 0.0814 -> 8.5%. CI 상한은 최대 1.2202(22%)라 쓰지 않는다. n 약 100~117에서 p99는 상위 1~2건이 좌우한다 |

- 현 판정기 기본값(속도 평균 m=1%, 꼬리 `max(1%, aa_noise)`이고 aa_noise는 최대 2m=2%)은 이 조건에서 A/A조차 NO-CHANGE를 못 낸다(위 INCONCLUSIVE 5/5). 1단계에서 판정기 판정만 보면 모든 후보가 꼬리 hold로 INCONCLUSIVE가 되고, 꼬리 CI를 좁히려면 표본을 늘려야 한다(`noninferiority`의 hold는 "표본을 늘려 다시 판정"이다).
- 두 가지 길이 있다. 어느 쪽을 쓸지는 코디네이터·1단계 티켓이 정한다(이 티켓은 하네스를 바꾸지 않는다).
  - 길 1: 위 표의 허용 폭을 점추정 문턱으로 쓴다. 판정 JSON의 `ratio` 값을 문턱과 직접 비교한다. 이때 길 1이 대체하는 것은 CI 기반 p95/p99 `judge.noninferiority` 판정(CI 하한 > 1 + `max(1%, aa_noise)`이면 `regressed`)뿐이다. 그 문턱은 위 권장 폭보다 훨씬 좁아 같은 run이 판정기에서는 FAIL(1), 점추정 규칙에서는 통과로 갈릴 수 있다(예: p95 비 1.025, CI [1.012, 1.04]). 반대로 쿼리별 꼬리 초과 검사(`tail["regressed"]`, `bench/judge.py` 318-322행, 위 "쿼리별 꼬리 초과" 열)는 그대로 유지된다. 길 1을 고르면 1단계 기준에 "CI 기반 p95/p99 판정은 이 표로 대체하고 쿼리별 꼬리 초과 검사는 판정기 그대로"라고 명시해야 한다.
  - 길 2: 조건을 키운다. 꼬리 CI 반폭은 대략 1/sqrt(n)이다(근사, 미실측). 152쿼리 전체 x 3라운드면 n이 약 4배(약 450)라 p95 반폭이 약 1.6%로 줄 것으로 추정한다. 그래도 1% 미만은 안 되고, 1 run이 약 80분 x 3팔 확장이라 약 2시간이 든다. 이때는 이 보고의 폭을 다시 재야 한다.
- 이 폭은 v1.0.0 복제본 기준이다. 1단계 기준선 arm은 운영 창 뒤 v1.1.0 복제본에서 재므로, 그때 흔들림이 크게 다르면(예: 정확도가 비결정이 되면) 폭을 다시 정한다(#284 범위 밖: v1.1.0 복제본 측정).
